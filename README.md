## 書く、組み立てる

**太字**、*斜体*、~~取り消し線~~、==マーカー==。
リンクや表、脚注も、いつもの記法で書けます。[^note]

| 書きたいもの | 記法 |
| :--- | :--- |
| 図とフロー | Mermaid |
| 数式 | LaTeX / KaTeX |
| 楽譜 | ABC記譜法 |

- [x] まずは、書き始める
- [ ] 自分のアイデアを加える

## 数式を添える

インライン数式は $e^{i\pi}+1=0$ のように。
ブロック数式は独立した行に表示できます。

$$
\int_{-\infty}^{\infty} e^{-x^2}\,dx = \sqrt{\pi}
$$
